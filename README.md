# ИС фитнес-клуба «ПУЛЬС» — UI/UX проект

Учебный проект: информационная система фитнес-клуба. Пройден полный UX-цикл:
ТЗ → скелет (структура) → вайрфреймы (lo-fi) → рабочий сайт (hi-fi) → дизайн-система и экраны в Figma → интерактивный прототип.

## Структура репозитория

| Путь | Что это |
|---|---|
| `tz.pptx` | Техническое задание (US-01..06, FR-01..06, BR-01, NFR-01..05, UC-01..04) |
| `tz_extract.txt` | Текстовая выжимка ТЗ |
| `db.xlsx` | Словарь БД и матрица трассировки |
| `db_extract.txt` | Текстовая выжимка БД |
| `PROJECT_PROGRESS.md` | Полный журнал проекта: карта узлов Figma, решения, лимиты, этапы |
| `serve.ps1` | Локальный сервер: `powershell serve.ps1` → http://localhost:8766 |
| `site/` | Все HTML-экраны и версии |

## Три уровня детализации сайта

1. **`site/skeleton.html`** — скелет: статичная структурная схема (21 экран, 19 связей, альтернативы потоков)
2. **`site/lofi.html`** — вайрфреймы: все 18 экранов, низкодетализированные, с навигацией
3. **`site/index.html`** — рабочий сайт (SPA): полный функционал

## Рабочий сайт — возможности

- Роли: гость / клиент / тренер / администратор (демо-доступы: `client@puls.ru / demo`, `trainer@puls.ru / demo`, `admin@puls.ru / demo`)
- UC-01: покупка абонемента (успех / ожидание / отказ, автоактивация)
- UC-02: запись на занятие с проверками BR-01 (места, абонемент, дубль)
- UC-03: отмена с правилом 2 часов и возвратом посещения
- UC-04: отметка посещения тренером → история клиента
- Админ: статистика, управление расписанием и тарифами

## Прочие экраны

- `c01–c14.html` — клиентские экраны (по одному)
- `t01–t03.html` — тренер, `a01–a03.html` — админ
- `res-mob.html` / `res-tab.html` — адаптив 390px и 768px
- `trace.html` — матрица трассировки, `pres.html` — презентация проекта
- `proto.html` — архивный навигатор прототипа
